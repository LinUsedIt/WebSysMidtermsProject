**PROJECT REQUIREMENTS**

This is a Graphics and Compression learning website that teaches people/students on Raster and Vector graphics and file compression.



**The website will contain the following pages:**

* **Home (index)**

  * The home page of the website. It will contain a quick introduction on the topic
* **Graphics**

  * This page contains the explanation and examples for Raster and Vector graphics
  * **Content Flow:**

    * Raster
    * Vector
    * Raster vs. Vector
* **Compression**

  * This page contains the explanation and examples for file compression and the RLE algorithm
  * Will contain 2 audio files (1 uncompressed, 1 compressed) and a zip file of the 2 audio files

    * These files can be downloaded and played



**Page Specs:** (refer to the wireframe for reference)

* **Overall**

  * Each page must have a responsive navbar

    * Hovering over a link changes its color and background
    * Current page link is different from the other links
  * Each page must have a "main" container that is centered and contains the following:

    * The Page title
    * The topic content (to be defined by the user)
    * A Technical Media Spec at the bottom (refer to the Midterms Instructions pdf file for reference. Can be found in the specs folder)
    * NOTE: The container is smaller than the background---there is space in between the left and right edges of the screen
  * Each page has a footer that contains the following information:

    * Copyright "<alias>" <student-name> 2026
    * NOTE: User will be the one to input this
  * Every image must have a label underneath them (Do not generate images, user will provide them in the assets folder)
  * Every content (explanation and paragraph) will be inputted by the user
  * Font:

    * San-serif with a retro feel
    * Body line-height 1.5. letter-spacing on headings and labels. font-kerning: normal
  * Every page and element is optimized for responsive mobile layout
